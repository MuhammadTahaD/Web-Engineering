============================================================
6. CHECK BEFORE PUSHING
============================================================

Always check:

git status

See which files Git is tracking:

git ls-files

Check the repository location:

git rev-parse --show-toplevel

Expected:

E:/Semester_05/4. Web_Engineering

Check GitHub remote:

git remote -v

Expected:

origin  https://github.com/MuhammadTahaD/Web-Engineering.git
origin  https://github.com/MuhammadTahaD/Web-Engineering.git


============================================================
7. CHECK FOR ACCIDENTAL NESTED REPOSITORIES
============================================================

Run:

find . -type d -name ".git"

EXPECTED OUTPUT:

./.git

If you see:

./.git
./Labs/01/.git
./Labs/02/.git
./Projects/Project_01/.git

then STOP.

Do NOT push.

You have accidentally created nested Git repositories.


============================================================
8. IF YOU ACCIDENTALLY RUN "git init"
============================================================

Example:

cd Labs/04
git init

WRONG.

Remove ONLY the Git metadata:

rm -rf .git

IMPORTANT:
This does NOT delete your project/lab files.

Then return to the main repository:

cd ../..

Check:

git status


============================================================
9. CHECK CURRENT BRANCH
============================================================

git branch

You should normally see:

* main

If you're on master:

git branch -M main


============================================================
10. IF REMOTE ORIGIN IS MISSING
============================================================

Check:

git remote -v

If nothing appears:

git remote add origin https://github.com/MuhammadTahaD/Web-Engineering.git

Then:

git push -u origin main

After that, normal pushes only require:

git push

============================================================
12. IF "FETCH FIRST" ERROR APPEARS
============================================================

Error:

! [rejected] main -> main (fetch first)

DO NOT immediately use:

git push --force

Instead:

git pull origin main --allow-unrelated-histories

If Git opens Vim:

Press:
Esc

Type:

:wq

Press Enter.

Then:

git push
